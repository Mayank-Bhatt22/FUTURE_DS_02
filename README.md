# FUTURE_DS_02
This dashboard analyzes the performance of multiple social media campaigns across platforms. It highlights total revenue, impressions, clicks, and conversions while comparing ad spend vs. revenue. Interactive visuals help track campaign trends, platform performance, and daily engagement patterns.

## 📁 Overview
This project presents an interactive dashboard designed to analyze the performance of multiple social media marketing campaigns. It provides valuable insights into revenue, impressions, clicks, and conversions across different platforms and campaign types.

---

## 🎯 Objectives
- Monitor and compare campaign performance across platforms  
- Analyze revenue vs. ad spend for each campaign  
- Track daily engagement trends  
- Identify high-performing countries, platforms, and campaigns  
- Help teams make data-driven marketing decisions  

---

## 🧰 Tools & Technologies
- **Power BI** – Dashboard creation & visuals  
- **Excel/CSV** – Data cleaning and preprocessing  
- **DAX** – Measures and calculated fields  
- **Data Visualization** – Trends, comparisons, KPIs  

---

## 📊 Key Insights
- Festival Bonanza and Big Billion campaigns generated the highest revenue  
- Instagram and YouTube contributed the highest campaign counts  
- Users showed fluctuating engagement over months, with several spikes in impressions  
- Daily trends reveal correlation between clicks, impressions, and conversions  

---

## 📈 Dashboard Features
- KPIs: Total Revenue, Impressions, Conversions, Clicks  
- Bar chart: Revenue vs. Ad Spend by Campaign  
- Donut chart: Campaign count by Platform  
- Line chart: Clicks, Conversions & Impressions over time  
- Slicers: Month, Country, Platform, Campaign Name  

---

## 📦 Dataset Information
The dataset includes:  
`Date`, `Campaign_Name`, `Country`, `Platform`, `Clicks`, `Conversions`, `Impressions`,  
`Revenue_$`, `Ad_Spend_$`.
